# Documentation

This documentation is split into two versions: The online version, which is always up to date, and the PDF version, which is a snapshot of the documentation at a certain point in time. The PDF version is available for download at the bottom of this page.

For the web version, you can visit the [TiefPrompt Web Documentation](/docs/web) page. For the PDF version, you can download it from [here](/docs/bundle.pdf).

Thanks for using TiefPrompt! We hope you enjoy it and find it useful. If you have any questions or feedback, please don't hesitate to reach out to us.
