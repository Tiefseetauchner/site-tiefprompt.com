# Countdown Timer

The countdown timer is a critical feature when working alone or without a remote. It allows you to start your script at your pace, when you're ready, and when you're back in frame.

![Countdown timer in action](/images/features/countdown-timer.webp){.w-100}

When using the countdown timer, it will wait for you before starting the script --- perfect if you just need a little time to get to your spot. It also makes it far easier to do retakes --- no more guessing where you have to scroll, simply pause and restart the prompter.
