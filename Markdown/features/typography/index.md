# Typography Control

Reading off a prompter three feet away is a completely different thing from reading off one across the room. The text has to be sized and laid out for the distance, so TiefPrompt lets you tune it.

![Typography control in action](/images/features/typography.webp){.w-100}

Set the font size to whatever's comfortable from where you're standing, and choose the alignment that reads best for you --- left, center, right, or fully justified. Combined with the [font choice](/features/font-choice), you get text that's actually shaped for how you read.

Big screen far away or a phone on a tripod up close, the text bends to your setup rather than the other way round.
