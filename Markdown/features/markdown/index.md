# Markdown Formatting

`P`{.badge .text-bg-warning .prem-font} *This feature requires a one-time purchase on Google Play or the App Store. It is fully free on F-Droid and self-compiled builds.*

So you know Markdown? You can just use it. Headings, bold, italic --- it all renders while you're reading the script.

![Markdown formatting in action](/images/features/markdown.webp){.w-100}

Honestly I added this mostly because I wanted to visually separate sections in my scripts without just putting a bunch of dashes. It works really well for that.

`0.12.1`{.badge .text-bg-warning .prem-font} Markdown Support is nowhere complete. Currently, only a small subset of Commonmark is supported, with a few additional quirks that I found useful. If there's something missing, don't hesitate to make a github issue, either on TiefPrompt or on the Markdown parser's repository at [GitHub](https://github.com/Tiefseetauchner/tief_weave).
