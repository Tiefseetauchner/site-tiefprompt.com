# Support

Do you need support? Have a feature request? A bug? Well, contact us!

The primary way to get support is via [Github](https://github.com/Tiefseetauchner/tiefprompt). You can create an issue there for bugs, feature request, so on.

[![Github Issues](https://img.shields.io/github/issues/Tiefseetauchner/tiefprompt?style=flat-square&label=GitHub%20Issues)](https://github.com/Tiefseetauchner/tiefprompt/issues)

However, if you have a support issue that requires direct contact (e.g. a security vulnerability, an issue that includes personal identifiable information, ...), or you don't want to make a Github account, you can email us at [support@tiefprompt.com](mailto:support@tiefprompt.com).
