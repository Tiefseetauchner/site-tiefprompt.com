# Filing Issues

{{ anchor: '04Contributing/01FilingIssues.md' }}

TiefPrompt is an open-source project, and we welcome contributions from the community. If you encounter a bug, have a feature request, or want to contribute in any way, please file an issue on our GitHub repository.

## Filing a Bug Report

When filing a bug report, please provide as much information as possible to help us reproduce and fix the issue. This includes the version of TiefPrompt you are using, the operating system and version where applicable, and a detailed description of the steps to reproduce the bug. Screenshots or screen recordings can also be very helpful. Also please include a log with your report. You can find the log file in the app's settings under "View Logs".

## Filing a Feature Request

When filing a feature request, please provide a clear and concise description of the feature you would like to see implemented. Explain the problem it solves or the improvement it brings to the user experience. While not necessary, if possible, include mockups or examples of similar features in other applications to make our development easier.
