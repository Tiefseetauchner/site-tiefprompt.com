# Markdown

{{ anchor: '03Features/08Markdown.md' }}

Markdown support is provided by its own library, `tief_weave`, and is limited to a few features.

Supported are, among others, headings, bold, and italics. To enable markdown, toggle the setting in the prompter or the Text Settings screen.

Markdown rendering using `tief_weave` is currently very limited and does not follow CommonMark. It is a best effort model designed for simple texts.

When markdown rendering is enabled, one may also enable Current Chapter Headings, which will display the most recent markdown heading at the top of the screen.

The rendered overlay can also be used to jump to the previous chapter.
